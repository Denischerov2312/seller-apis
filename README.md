# Репизоторий для работы с данным ozon, Яндекс маркет.
Данный репозиторий работает с товарами на таких площадках, как OZON и Яндекс Маркет.
Скачиваются данные о товарах casio, затем характеристики этих товаров обновляеются
на маркетплэйсах.

## seller.py
Работает с маркетплэйсом OZON.
### Что умеет?
Скрипт имеет несколько фунцкий:
* Получает данные о товаре casio.
* Работает для компаний, чей id указан.
* Отправляет запрос об изменении количества товаров на сайт OZON.
* Изменяет цены товара в базе данных OZON.
  
### Что потребуется для работы:
Для доступа к изменения данных, вы должно иметь токен продавца, получаемый на сайте OZON.
А также надо иметь id клиента. Эти данные записываются в `.env` файл, расплагающийся в корне проекта.
Данные записываются в формате:
`ПЕРЕМЕННАЯ`=`ЗНАЧЕНИЕ`
Пример:
```
SELLER_TOKEN=13lkjlkf
CLIENT_ID=2131jkljldf
```

### Как запустить?
Для запуска необходимо иметь python третьей версии.
Необходимо установить репозиторий себе на ПК.
И запустить его командой:
```
python seller.py
```

## market.py
Работает с "Яндекс Маркет".
### Что умеет?
Содержит такие функции, как:
* Cкачивает данные об остатках товара, с сайта casio.
* Отправляет запрос об изменении количества товаров на Яндекс маркете.
* Изменяет цены товара в Яндекс маркете.
### Разница FBS и DBS:
* `FBS` — Проще говорят, это когда продавец самостоятельно хранит, упаковывает и отправляет свои товары покупателям, но использует для этого инфраструктуру и логистические услуги маркетплейса (например, Wildberries, OZON).
* `DBS` — Это немного другое, когда продавец хранит товары на собственном складе и самостоятельно занимается всей логистикой — от упаковки до отправки и обработки возвратов.

###  Что потребуется для работы:
Все также, для доступа к сервису яндекс потребутеся токен.
И также `id` компании, с товарами которой будете работать.
Отдельно указываются данные для `FBS` и `DBS` компании. (Об отличи можно прочитать выше).
И требуется указать `id`складов(WAREHOUSE).
Данные записываются в формате:
`ПЕРЕМЕННАЯ`=`ЗНАЧЕНИЕ`
Эти данные записываются в `.env` файл, расплагающийся в корне проекта.
Пример:
```
MARKET_TOKEN = "mk_token_7a7b3c9f2e"
FBS_ID = "8842"
DBS_ID = "6734"
WAREHOUSE_FBS_ID = "wh_fbs_5523"
WAREHOUSE_DBS_ID = "wh_dbs_9457"
```
